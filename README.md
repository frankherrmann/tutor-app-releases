# Tutor-App — Downloads

Offizielle Installationsdateien der **Tutor-App**, einem lokalen Desktop-Werkzeug
für Oberstufen-Tutorinnen und -Tutoren am beruflichen Gymnasium in Hessen.

> **Alle Infos, Screenshots und Handbuch:**
> **<https://drherrmann.org/downloads/tutor-app/>**

Dieses Repository enthält **ausschließlich die fertigen Installationsdateien**
(unter „Releases"). Der Quellcode ist nicht öffentlich.

---

## Herunterladen

Diese Links zeigen **immer auf die neueste Fassung** und ändern sich nie:

| System | Download |
|---|---|
| **macOS** (Intel + Apple Silicon) | [Tutor-App-macOS.dmg](../../releases/latest/download/Tutor-App-macOS.dmg) — signiert und von Apple notarisiert |
| **Windows 10/11** | [Tutor-App-Windows-Setup.exe](../../releases/latest/download/Tutor-App-Windows-Setup.exe) — empfohlen |
| Windows (Alternative für Administratoren) | [Tutor-App-Windows.msi](../../releases/latest/download/Tutor-App-Windows.msi) |

Jedem Release liegen dieselben Dateien zusätzlich **mit Versionsnummer im Namen**
bei (z. B. `Tutor-App_2.16.0_universal.dmg`), falls eine bestimmte Fassung
gebraucht wird. Alle Fassungen: **[Releases](../../releases)**.

Jedes veröffentlichte Release enthält **immer sowohl eine macOS- als auch eine
Windows-Fassung**. Solange nicht beide vorliegen, bleibt das Release ein
Entwurf und ist hier nicht sichtbar — die Links oben zeigen dann weiterhin auf
die letzte vollständige Fassung und laufen nie ins Leere.

**Hinweis zu Windows:** Der Windows-Installer ist nicht code-signiert. SmartScreen
zeigt beim ersten Start eine Warnung — über „Weitere Informationen" →
„Trotzdem ausführen" lässt sie sich bestätigen. Auf macOS tritt das nicht auf.

## Kostenlos und ohne Einschränkungen

Die Tutor-App ist **kostenlos** nutzbar, im vollen Funktionsumfang. Es gibt keine
Testphase, keine Seriennummer und keine Registrierung.

Wer eine frühere Fassung als Testversion oder mit Seriennummer genutzt hat, muss
nichts tun: Nach dem Update entfällt die Lizenzprüfung, die Daten bleiben
unverändert.

---

## Datenschutz

Alle Daten liegen **ausschließlich lokal** auf dem eigenen Gerät, verschlüsselt
mit einem selbst vergebenen Master-Passwort. Es gibt keine Cloud-Anbindung und
keine Telemetrie. Der einzige Netzwerkzugriff ist die **manuell ausgelöste**
Update-Prüfung: Sie fragt hier bei GitHub die Nummer der neuesten Version ab und
überträgt dabei keine personenbezogenen Daten und keine Kennungen aus der App.
